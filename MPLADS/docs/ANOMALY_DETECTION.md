# ML anomaly detection

Isolation Forest runs only when at least 100 real records have all supported financial features. Features are log sanction amount, log expenditure, expenditure/sanction ratio, transaction count, and payment concentration. The model uses a fixed random seed (9047), 200 estimators, one worker, and contamination 0.05. Each run stores the feature list, configuration, model version, release version, and eligible-record count.

An ML anomaly signal means an observation differs from the learned dataset distribution. It is not an allegation or finding.
