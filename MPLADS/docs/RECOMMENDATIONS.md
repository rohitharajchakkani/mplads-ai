# Evidence-based recommendations

Recommendations are deterministic review guidance generated only from persisted active-release evidence. They never state or imply wrongdoing.

Triggers include financial/payment signals, lifecycle signals, duplicate-candidate signals, ML anomaly signals, high or very-high monitoring priority, and direction-aware peer bottlenecks. Each recommendation stores the exact evidence references that triggered it, plus source release, priority, type, timestamp, and deterministic fingerprint.

Examples of allowed language include reviewing supporting expenditure records, comparing contextual work evidence, or reviewing available source documentation. Recommendations do not invent actions where evidence does not exist.
