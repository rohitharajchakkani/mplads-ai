# Ask AI limitations

Ask AI answers only the registered, database-backed monitoring questions. It cannot access source files, run SQL, reveal system prompts or secrets, write records, predict future outcomes, infer physical progress, or make findings of fraud or corruption.

Entity matching is exact against entities visible in the caller's authorized data. A unique match can be applied as a filter. Multiple matches produce a clarification response; absent entities produce an honest not-found response. The system does not guess entities.

Navigation links are built only from verified database identifiers or fixed protected routes. Gemini cannot create links, select tools, alter numerical values, or extend a user's scope.
