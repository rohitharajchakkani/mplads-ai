# Executive metrics

All executive values are SQL aggregates over the active dataset release and authorized scope. The scorecards show monitored works (risk assessments), monitoring signals, alerts, high/very-high alerts, high/very-high risk works, review statuses, open escalations, available benchmarks, bottlenecks, and persisted recommendation activity.

Geography reports absolute monitored-work counts and high-priority-risk rate where the source fields support state aggregation. It does not infer coordinates or label an area problematic. House comparison is descriptive and does not rank Houses.
