# Monitoring intelligence architecture

The protected intelligence layer reads only the active release, derives supported work-level features, applies separate deterministic evidence families, adds bounded duplicate-candidate analysis and a reproducible Isolation Forest evidence family, then stores signals, risk assessments, alerts, and run metadata. Public routes neither request nor expose these records.

`python -m app.intelligence.run` is the only execution entry point. Application startup never retrains a model or generates monitoring outputs.
